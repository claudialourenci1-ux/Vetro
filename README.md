# VETRO

**A inteligência por trás da operação comercial.**

VETRO é uma plataforma SaaS B2B de inteligência e gestão comercial para incorporadoras.

## Arquitetura

- Frontend: Next.js + TypeScript
- Backend: Supabase
- Autenticação: Supabase Auth
- Banco: PostgreSQL + RLS
- Storage: Supabase Storage
- Edge Functions: Supabase Functions
- Deploy: Vercel

## Módulos iniciais

- Overview
- Parceiros
- Pipeline
- Empreendimentos
- Intelligence / V6
- Equipe
- Importar dados
- Admin
